## Changes landed with this baseline

- **Log capture fix**: `run_ole_sweep.sh`, `run_linear_ole_sweep.sh`, `run_orca_fc_ringlpn_demo.sh`,
  `run_orca_fc_ideal_ole_transcript.sh` now append raw benchmark stdout to their `.log`
  files (previously only stderr was captured, leaving 0-byte logs on clean runs).
- **Canonical gate**: `run_paper_checkpoint_smoke.sh` now covers the host trio
  (expand/SPFSS/OLE), the secure-conversion prototype, q128 OLE and linear smokes
  (uniform + regular), and the ideal-OLE transcript, and ends with an explicit
  `ALL GATES PASS` marker.
- **Demo link fix**: `build_orca_fc_ringlpn_demo.sh` links `src/orca_globals_stub.cpp`
  (defines `OneGB`) — the backward-contract demo pulls in the DCF keygen path, which
  references this global; linking `utils/sigma_comms.cpp` instead would drag in the full
  comms stack.
- **Submodule fix**: added the missing `GPU-MPC/ringlpn/extern/NFLlib` mapping to
  `.gitmodules` (local checkout verified at the recorded gitlink commit `5cf40ed`,
  NFLlib v1.0.0-23). `git submodule status` no longer fatals.
- **Ownership normalized**: `bin/`, `host_bin/`, and `results/` had root-owned files from
  container builds; all now owned by the working user.

Known environment quirks (documented, not fixed): the `mnist` and `weights` data
submodules carry internal staged renames (e.g. `t10k-images.idx3-ubyte` →
`t10k-images-idx3-ubyte`) — left untouched, they predate this work. `bench_ntt`
requires libmpfr-dev, present only via container.

## Scope: what this baseline does and does not claim

Safe to state (all verified today):

- The byte-compatible Orca FC key-writer and the ideal-OLE dealerless FC transcript both
  validate through the **unchanged** `gpuMatmulBeaver` online path, for forward, dW and
  dX contracts, at q62 (bw ≤ 20) and q124 (bw ≤ 32) bounded constant-polynomial cases.
- Baseline Orca is byte-identical with `ORCA_RINGLPN_FC_KEYS` unset (verified by diff
  inspection and a passing two-party FC test built from the modified `fc_layer.cu`).
- The secure Z_M → Z_2^bw conversion prototype matches the oracle bit-for-bit with the
  measured cost above (semi-honest, party-separated; correlations from an offline dealer).
- q128 = two q62 CRT limbs (actual 124 bits, primes 2^62−33 and 2^62−51); these
  fully-split rings invoke the **splittable** Ring-LPN assumption, not irreducible
  Ring-LPN, and no concrete bit-security level is pinned (smoke parameters c=2, t=8 are
  correctness parameters, not security parameters).

Not yet claimable (deferred, tracked in `dealerless_orca_ringlpn_protocol_plan.tex`):

- "Trusted dealer removed" — transcript cross terms use an **ideal OLE oracle**; the
  key-writer derives both parties' randomness from a shared seed (dealer-equivalent).
- Real Figure 2 OLE wired into the FC transcript; distributed SPFSS key generation via OT.
- Dense packing (current artifacts use one scalar per polynomial, which defeats PCG
  amortization); constant-round comparator for the conversion (current ripple uses
  125–249 sequential rounds per output).
- Flag-ON operation through the real `FCLayer` at bw=64 (v1 key-writer supports bw ≤ 32;
  bw=64 fails fast by design).
- Malicious security; full Orca training; model-level benchmarks.
